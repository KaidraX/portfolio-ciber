# 🛡️ Ezequiel Amorim — Segurança Ofensiva

Portfólio de pentest: exploração de aplicações web, escalonamento de privilégio
(Linux e Windows) e relatório técnico. Cada writeup documenta a cadeia completa,
**o mecanismo por trás da falha** e **como corrigi-la**.

🔗 **Site:** https://ezequielpentest.github.io/portfolio-ciber/

---

## Conteúdo

- **`index.html`** — site (tema terminal, seções por plataforma).
- **`writeups/`** — writeups de laboratório (HTML): FIT Healthy, Cartão Seguro,
  Windows Scheduled Task, VulnHub Vikings.
- **`artigos/`** — notas técnicas por classe de vulnerabilidade (ex.: Linux PrivEsc).
- **`home-lab/`** — projeto do laboratório ofensivo (lab-as-code).
- **`build.py`** — script que gera as páginas a partir do fonte.

## Ética

Todo o conteúdo foi produzido em **ambientes autorizados** (plataformas de
treinamento e VMs próprias), com fins educacionais. Nada aqui deve ser usado
contra sistemas sem autorização por escrito.
