Arsenal de Linux Privilege Escalation

Estudo dirigido TÉCNICAS sudo/GTFOBinsLD_PRELOADcronSUIDNFS

resumo

Notas estruturadas de uma série de labs de privesc em Linux. O fio condutor é sempre o mesmo: quem escreve um recurso com privilégio menor que quem o executa quebra a fronteira de confiança. Abaixo, os vetores por família.

sudo & variáveis de ambiente

GTFOBins: sudo -l lista os binários; cada um é classificado pela função concedida (Shell, Command, File read/write…). Um sem função Shell (ex.: apache2) ainda pode dar leitura de arquivo.

LD_PRELOAD: com env_keep+=LD_PRELOAD, força o carregamento de um .so cujo __attribute__((constructor)) roda no load — antes de qualquer call — já como root.

LD_LIBRARY_PATH: sequestro por nome — só funciona com o nome exato de uma entrada NEEDED real, porque o linker dinâmico resolve pelo nome gravado no binário, não por caminho fixo.

sudo LD_PRELOAD=/tmp/preload.so <binário-permitido>   # shell root via constructor

cron & wildcard injection

PATH hijack: /etc/crontab com PATH controlável + script chamado sem caminho absoluto → planta-se um binário homônimo no PATH.

tar wildcard: tar -czf bk.tar.gz * — criar arquivos chamados --checkpoint=1 e --checkpoint-action=exec=sh.elf faz o glob expandi-los como flags do tar (argument injection). Mesma lógica em chown -R, rsync, zip.

SUID — do hunting ao Exim CVE-2016-1531

find / -perm -u+s -type f 2>/dev/null   # hunting de SUID

Exim (CVE-2016-1531): binário SUID root. PERL5OPT=-Mroot + PERL5LIB=/tmp carrega um módulo Perl do atacante antes do exim derrubar o privilégio — timing errado: env var controlada consumida por processo ainda privilegiado.

bash function import (bash < 4.2-048): uma função exportada com nome de caminho tem prioridade sobre o binário real, mesmo com caminho absoluto. PS4/xtrace: PS4='$(...)' com SHELLOPTS=xtrace executa a cada linha traçada.

NFS — no_root_squash

Sem root_squash, o UID 0 remoto permanece root no servidor. Monta-se o share, cria-se um binário SUID root e executa-se no alvo:

mount -o rw,vers=3 <alvo>:/tmp /mnt
msfvenom -p linux/x86/exec CMD="/bin/bash -p" -f elf -o /mnt/sh.elf
chmod +xs /mnt/sh.elf     # no alvo: /tmp/sh.elf → root
